# Claude for Teachers, 이제 학교와 학군에서 이용 가능

## 이 글이 뭔가요

발표 글. Claude for Teachers가 학교와 학군을 대상으로 무료 Enterprise 제공으로 열렸고, 자격 요건을
충족하고 2027년 6월 30일까지 등록한 조직은 1년간 무상 이용을 받는다. 학군 단위 버전이 더해주는 것
(중앙 관리 계정, 싱글 사인온, 역할 기반 접근 제어, 학군 단위 약관을 통한 FERPA 준수), 네 단계 설정
절차, 이미 인증된 교사의 이전 방식, 그리고 신학기에 맞춰 나온 두 가지 티칭 스킬을 다룬다.

## 언제 유용한가요

- 학군이 개별 교사 인증에서 중앙 관리 계정으로 옮겨가려 할 때.
- 프라이버시 또는 구매 검토에서 학생 데이터와 FERPA 관련 입장을 문서로 필요로 할 때.
- 어떤 교과나 기능을 먼저 도입할지 계획할 때.
- 등록 마감일과 그 마감일이 실제로 무엇을 제한하는지 확인해야 할 때.

## 핵심 포인트

- K-12 학교와 학군을 위한 **무료 Enterprise 제공**. 1년 무상 이용을 받으려면 **2027년 6월 30일까지 등록**.
- **중앙 관리 계정**은 **싱글 사인온**과 **역할 기반 접근 제어**를 포함한 엔터프라이즈 기능을 제공한다.
- K-12 수업을 위해 설계된 기능에 대한 **교육자 무료 이용**.
- **미국 50개 주 전체의 주 학업 표준에 정렬된 티칭 스킬.**
- 학군 단위 약관과 데이터 처리 계약을 통한 **FERPA 준수**.
- **설정:** 학군 인증 → K-12 약관 동의 → 이메일 도메인 연결 → 싱글 사인온 연결.
- **학군 도메인에서 이미 인증된 교사는 자동으로** 중앙 계정으로 이전된다.
- **학생 데이터는 모델 학습에 사용되지 않으며**, 학생 정보는 K-12 데이터 처리 계약으로 보호된다.
- **새 티칭 스킬 두 가지:** 수업의 핵심 순간 설계를 돕는 *Lesson Preparation*, 그리고 표준에 정렬된
  평가를 만들며 처음에는 수학에서 제공되는 *Check for Understanding*.
- **함께 개선된 것:** 학생 자료의 접근성 강화, 수업 계획 기능 업데이트.
