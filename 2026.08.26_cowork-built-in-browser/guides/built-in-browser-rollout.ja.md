# Cowork の内蔵ブラウザを展開する

## 何がリリースされたか

デスクトップアプリの Claude Cowork に、Claude 専用のブラウザが内蔵されました。タスクで Web サイトを
使う必要が生じると、サイドパネルにブラウザが開き、Claude がページを移動し、読み、クリックし、入力
します。

これはユーザーのブラウザではなく、Claude 自身のブラウザです。個人のブラウジングとは分離されており、
Claude がユーザーのタブ、ブックマーク、パスワードを見ることはありません。

## 対象と提供時期

- **Pro、Max、Team:** macOS、Windows、Linux（ベータ）へ 1 週間かけて順次展開されます。
- **設定は不要です。** Web を必要とするタスクを任せれば、サイドパネルにブラウザが開きます。
- **法人:** 管理者は **Organization settings → Cowork → Built-in browser** からすぐに有効化できます。

## ブラウザが動く場所

ブラウザはデスクトップアプリの中にあります。デスクトップアプリが開いていて接続されていれば、Web と
モバイルからも利用できます。デスクトップアプリのない Web のみの利用者は、引き続き Claude in Chrome
を使います。

その前提で計画してください。内蔵ブラウザに依存するワークフローは、操作する人が Web やスマートフォン
からであっても、どこかでデスクトップアプリが動いている必要があります。

## 既定のブラウザを選ぶ

Cowork には Web を操作する手段が 2 つになり、既定値はすでに Claude in Chrome を使っているかどうかで
切り替わります。**Settings → Cowork → Preferred browser** で明示的に指定してください。

アナウンスが示す使い分け:

- **内蔵ブラウザ** — 別の作業を続けている間に進めたい Web タスク。リサーチの収集、ベンダーポータル
  からの請求書のとりまとめなど。
- **Claude in Chrome** — すでに開いていてログイン済みのページでの作業。CRM の更新、受信トレイの
  処理、ドキュメントの編集など。

## ログインの設定

内蔵ブラウザは最初セッションを一切持ちません。ログインはサイト単位で取り込みます。

- **macOS:** Chrome、Edge、Firefox から。
- **Windows と Linux:** Firefox から。

金融・メール・SSO のサイトは、明示的に含めない限り既定で除外されます。この既定値をそのままにして
おくことが、ブラウザタスクの到達範囲を絞るいちばん簡単な方法です。

## 安全面の姿勢

内蔵ブラウザはプロンプトインジェクション、つまりページに隠された指示が Claude の動きをそらそうとする
攻撃にさらされます。内蔵ブラウザには Claude in Chrome と同じ safeguards が備わっており、操作が
ユーザーの依頼と一致しているかの確認も含まれます。これらはリスクを有意に減らしますが、完全には
なくせません。

信頼できる Web サイトから始めてください。さらに詳しい指針は、アナウンスが参照する安全性ドキュメント
にあります。

## 展開チェックリスト

1. プラットフォームを確認する。macOS、Windows、Linux（ベータ）のいずれかで、デスクトップアプリが
   インストールされていること。
2. 組織で使う場合は Organization settings → Cowork → Built-in browser で有効化する。
3. 推測された既定値に任せず、Settings → Cowork → Preferred browser で優先ブラウザを指定する。
4. 最初のタスクに必要なログインだけを取り込み、金融・メール・SSO は除外したままにする。
5. 信頼できるサイトと影響の小さいタスク（リサーチの収集、請求書のとりまとめ）から始め、そこから
   広げる。
