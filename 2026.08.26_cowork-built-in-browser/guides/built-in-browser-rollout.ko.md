# Cowork 내장 브라우저 도입하기

## 무엇이 출시되었나

데스크톱 앱의 Claude Cowork에 Claude 전용 브라우저가 내장되었습니다. 작업에 웹사이트가 필요하면
사이드 패널에 브라우저가 열리고, Claude가 웹페이지를 이동하며 읽고 클릭하고 입력합니다.

이것은 사용자의 브라우저가 아니라 Claude 자신의 브라우저입니다. 개인 브라우징과 분리되어 있으며,
Claude는 사용자의 탭, 북마크, 비밀번호를 절대 보지 않습니다.

## 누구에게, 언제

- **Pro, Max, Team:** macOS, Windows, Linux(베타)에 한 주에 걸쳐 순차 배포됩니다.
- **별도 설정은 필요 없습니다.** 웹이 필요한 작업을 맡기면 사이드 패널에 브라우저가 열립니다.
- **엔터프라이즈:** 관리자는 **Organization settings → Cowork → Built-in browser**에서 바로 켤 수
  있습니다.

## 브라우저가 실행되는 곳

브라우저는 데스크톱 앱에 있습니다. 데스크톱 앱이 열려 있고 연결되어 있으면 웹과 모바일에서도 사용할
수 있습니다. 데스크톱 앱 없이 웹만 사용하는 경우에는 계속 Claude in Chrome을 사용합니다.

이 점을 감안해 계획하세요. 내장 브라우저에 의존하는 워크플로는, 이를 조작하는 사람이 웹이나
휴대폰에 있더라도 어딘가에서 데스크톱 앱이 실행되고 있어야 합니다.

## 기본 브라우저 선택

이제 Cowork에서 웹을 다루는 방법이 두 가지이며, 기본값은 이미 Claude in Chrome을 쓰고 있는지에 따라
전환됩니다. **Settings → Cowork → Preferred browser**에서 명시적으로 지정하세요.

공지에서 제시한 기준:

- **내장 브라우저** — 다른 일을 계속하는 동안 돌아가야 하는 웹 작업. 리서치 수집, 공급업체 포털에서
  청구서 모으기 등.
- **Claude in Chrome** — 이미 열어 두고 로그인해 둔 페이지 작업. CRM 업데이트, 받은편지함 처리,
  문서 편집 등.

## 로그인 설정

내장 브라우저에는 처음에 아무 세션도 없습니다. 로그인은 사이트 단위로 가져옵니다.

- **macOS:** Chrome, Edge, Firefox에서.
- **Windows와 Linux:** Firefox에서.

금융, 이메일, SSO 사이트는 명시적으로 포함하지 않는 한 기본적으로 제외됩니다. 이 기본값을 그대로
두는 것이 브라우저 작업의 접근 범위를 제한하는 가장 간단한 방법입니다.

## 안전 태세

내장 브라우저는 프롬프트 인젝션에 노출됩니다. 페이지에 숨겨진 지시문이 Claude의 방향을 틀려고 하는
공격입니다. 내장 브라우저에는 Claude in Chrome과 동일한 안전장치가 적용되며, 여기에는 동작이
사용자의 요청과 일치하는지 확인하는 검사가 포함됩니다. 이 장치들은 위험을 유의미하게 줄이지만
완전히 없애지는 못합니다.

신뢰할 수 있는 사이트부터 시작하세요. 추가 지침은 공지가 안내하는 안전 문서에 있습니다.

## 도입 체크리스트

1. 플랫폼 확인: macOS, Windows, Linux(베타) 중 하나에 데스크톱 앱이 설치되어 있어야 합니다.
2. 조직 단위라면 Organization settings → Cowork → Built-in browser에서 활성화합니다.
3. 추론된 기본값에 맡기지 말고 Settings → Cowork → Preferred browser에서 선호 브라우저를 지정합니다.
4. 초기 작업에 필요한 로그인만 가져오고, 금융·이메일·SSO는 제외된 상태로 둡니다.
5. 신뢰할 수 있는 사이트와 영향이 작은 작업(리서치 수집, 청구서 모으기)부터 시작한 뒤 범위를
   넓힙니다.
