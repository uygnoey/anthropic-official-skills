# The two browsers, side by side

Both options let Claude act on the web. They differ in whose browser session the work happens in.

| | Built-in browser (Cowork desktop) | Claude in Chrome |
| --- | --- | --- |
| Where it runs | A browser inside the desktop app, opening in the side panel | Your own Chrome window |
| Relationship to your browsing | Separate — Claude never sees your tabs, bookmarks, or passwords | Inside the browser you are already using |
| Sessions available | Only logins you import, site by site | The accounts you are already signed into |
| Best for | Web work that should run while you stay productive elsewhere | Pages you already have open and are signed into |
| Typical tasks named in the announcement | Gathering research; collecting invoices from vendor portals | Updating a CRM; working through an inbox; editing a document |
| Availability | Desktop app; usable from web and mobile while the desktop app is open and connected | Chrome, including for web-only users without the desktop app |

## Choosing the default

The default preference switches based on whether you already use Claude in Chrome. To set it
yourself: **Settings → Cowork → Preferred browser**.

## Deciding case by case

1. Does the task depend on a page that is already open, or a session already signed in? → Claude in
   Chrome.
2. Would you rather the task ran beside your work instead of inside it? → built-in browser.
3. Does the task need a site whose login you would not want to import (banking, email, SSO)? → keep
   it out of the built-in browser; do it in Chrome under your own eyes, or not at all.
