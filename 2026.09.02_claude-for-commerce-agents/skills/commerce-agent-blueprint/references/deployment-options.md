# Deployment options and ecosystem

## Where a commerce agent can run

The same blueprint deploys on any of:

- **Claude API**
- **Amazon Bedrock**
- **Microsoft Foundry**
- **Google Cloud Vertex AI**

Pick based on where the rest of your commerce stack and your data already live; the agent design
does not change between them.

## Partner ecosystem

Announced partners for commerce agent work: **Accenture**, **Mastercard**, **Visa**.

## Where trust sits in the design

The commerce partners frame the same constraint the blueprint's guardrails encode:

- Visa (Jack Forestell, Chief Product and Strategy Officer): *"AI will fundamentally reshape
  commerce, but trust must remain at the center of every transaction."*
- Mastercard (Sherri Haymond, Executive VP): *"Trust is the currency of commerce, and it is even
  more critical in the agentic era."*

Accenture (Kath Gramling, Global Consumer Goods Lead) notes 85% openness to AI collaboration, and
that nearly 75% would trust a personal agent more than close friends for purchases.

## Who is building on it

- **Shopify** — merchants can build agents that help customers find products, check out, and
  answer order questions.
- **Priceline** — its agent Penny handles trip planning: *"A trip is one of the most complex
  things a person buys... Penny navigates all of that in one conversation."*
- **Square** — agentic tools that monitor sales, labor and inventory while keeping sellers in
  control.
