# Rollout and admin controls

## Availability

Claude in Chrome is generally available on **all paid Claude plans**.

## What it can do

- Reach tools that have no native integration: internal dashboards, legacy systems, vendor portals.
- View web pages and act on them — reading text, clicking links, navigating, filling forms.
- Work across browser tabs while the conversation continues in the desktop, mobile, and web apps.
- Authenticate using the logins already present in the browser.

## Autonomous action approval

Safe actions are approved automatically, using the same mechanism as auto mode in Claude Code.
Users can override this behavior.

## Installing

Individuals install Claude in Chrome from the Chrome Web Store.

## Enterprise administration

Enterprise admins manage it through **Organization Settings**, including **domain restrictions** —
scoping which sites are in reach. Deciding that domain list is the primary deployment-time control:
start from the systems the team genuinely needs and widen from there, rather than enabling the open
web and narrowing later.
