# Claude in Chrome が一般提供開始

## この記事について

製品アナウンス。Claude in Chrome がすべての有料 Claude プランで一般提供（GA）となり、安全性の検証を
伴う自律的なブラウザ操作が利用できるようになった。記事は、ブラウザ操作が何のためのものか——ネイティブ
統合のないツールに届くこと——、安全なアクションがどのように自動承認されるようになったか、そして
プロンプトインジェクションに対して展開された 3 層の保護とレッドチーム評価の数値を扱う。

## どんなときに役立つか

- コネクタが存在しない社内ダッシュボード、レガシーシステム、ベンダーポータルにワークフローが依存
  しているとき。
- ブラウザセッション内でエージェントに行動させるかを判断しており、何が自動承認され何がそうでないか
  を知りたいとき。
- セキュリティレビュー担当にプロンプトインジェクションのリスクと緩和策を説明する必要があるとき。
- エンタープライズ管理者として、ブラウザ操作が到達できるドメインの範囲を決めるとき。

## 主なポイント

- **すべての有料プランで一般提供。** 個人ユーザーは Chrome ウェブストアからインストールする。
- **ユースケースはリーチ。** ネイティブ統合のない社内ダッシュボード、レガシーシステム、ベンダー
  ポータル。
- **ブラウザ内でできること。** ページを閲覧して操作する——テキストを読む、リンクをクリックする、
  ページ遷移する、フォームに入力する——タブをまたいで作業し、既存のログインで認証する。その間、会話は
  デスクトップ・モバイル・ウェブのアプリで続けられる。
- **安全なアクションは自動承認される。** Claude Code の auto mode と同じ仕組みで、ユーザーによる
  上書きも可能。
- **脅威は注入された指示。** 悪意ある行為者は、ウェブページ・メール・フォームフィールドといった
  ウェブコンテンツに指示を隠し、AI エージェントの向きを変えようとする。
- **3 層の保護。** 拡大し続ける攻撃ライブラリ（社内の自動化ツール、外部レッドチーム、実環境の
  モニタリングから供給）に対する強化されたモデル学習、Claude が行動する前のウェブコンテンツの
  プローブ検査、そしてアクションがユーザーの要求と一致するかを確認するアクション検証分類器。
- **評価結果。** より強力なレッドチーム攻撃に対し、Claude Opus 5 はセーフガード適用前で 3.8% の攻撃
  成功率を示した。プローブと安全分類器を適用すると、Sonnet 5 と Opus 5 は 0%、Fable 5 は 0.3%。
- **管理者向けコントロール。** エンタープライズ管理者は Organization Settings で管理し、ドメイン制限
  もここに含まれる。
