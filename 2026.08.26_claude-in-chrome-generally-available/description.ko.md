# Claude in Chrome 정식 출시

## 이 글이 뭔가요

제품 발표. Claude in Chrome이 모든 유료 Claude 플랜에서 정식 출시(GA)되어, 안전성 검증을 갖춘 자율
브라우저 동작을 제공한다. 글은 브라우저 제어가 무엇을 위한 것인지 — 네이티브 통합이 없는 도구에
도달하는 것 — , 안전한 동작이 이제 어떻게 자동 승인되는지, 그리고 프롬프트 인젝션에 맞서 배포된 세
겹의 보호 계층과 레드팀 평가 수치를 다룬다.

## 언제 유용한가요

- 커넥터가 없는 사내 대시보드, 레거시 시스템, 벤더 포털에 워크플로가 의존할 때.
- 브라우저 세션 안에서 에이전트가 동작하도록 허용할지 판단하면서, 무엇이 자동 승인되고 무엇이
  아닌지 알고 싶을 때.
- 보안 검토자에게 프롬프트 인젝션 위험과 완화책을 설명해야 할 때.
- 엔터프라이즈 관리자로서 브라우저 제어가 도달할 수 있는 도메인 범위를 정할 때.

## 핵심 포인트

- **모든 유료 플랜에서 정식 출시.** 개인은 Chrome 웹 스토어에서 설치한다.
- **핵심 용도는 도달 범위.** 네이티브 통합이 없는 사내 대시보드, 레거시 시스템, 벤더 포털.
- **브라우저 안에서 할 수 있는 일.** 페이지를 보고 동작한다 — 텍스트 읽기, 링크 클릭, 이동, 폼
  작성 — 탭을 넘나들며 작업하고, 기존 로그인으로 인증한다. 그동안 대화는 데스크톱·모바일·웹 앱에서
  이어진다.
- **안전한 동작은 자동 승인된다.** Claude Code의 auto mode와 동일한 메커니즘이며, 사용자가 재정의할
  수 있다.
- **위협은 주입된 지시문이다.** 악의적 행위자는 웹 페이지, 이메일, 폼 필드 같은 웹 콘텐츠에 지시문을
  숨겨 AI 에이전트의 방향을 돌리려 한다.
- **세 겹의 보호 계층.** 계속 늘어나는 공격 라이브러리(내부 자동화 도구, 외부 레드팀, 실제 환경
  모니터링에서 수집)를 대상으로 한 강화된 모델 학습, Claude가 동작하기 전 웹 콘텐츠에 대한 프로브
  스크리닝, 그리고 동작이 사용자 요청과 일치하는지 확인하는 동작 검증 분류기.
- **평가 결과.** 더 강한 레드팀 공격에 대해 Claude Opus 5는 보호 장치 적용 전 3.8%의 공격 성공률을
  보였다. 프로브와 안전 분류기를 적용하면 Sonnet 5와 Opus 5는 0%, Fable 5는 0.3%였다.
- **관리자 통제.** 엔터프라이즈 관리자는 Organization Settings에서 관리하며 도메인 제한도 여기서
  설정한다.
