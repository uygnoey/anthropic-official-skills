# Digest message template

The output shape. Fill this in once by hand for a real recipient and pass it as the example to
match — a concrete filled-in sample communicates the format better than a description of it.

The organizing idea is the **top three things for the week**, prioritizing items the recipient
can act on.

---

## Template

```
Hi [First name],

**Top three things this week**

1. [Most actionable item — what to do, for which account, and by when]
2. [Second most actionable item]
3. [Third most actionable item]

**Field events in your territory**
- [Event name] — [date], [city]. [Registration link, only if present in source data]
  Audience: [target title/segment]. Your matching accounts: [account names]

**Registrants from your accounts for upcoming webinars**
- [Contact name], [title] at [account] — registered for [webinar], [date]

**Marketing content worth sharing**
- [Blog article / eBook / customer story] — [why it fits this rep's accounts]

**Suggested follow-ups**
- [Specific follow-up tied to one of the items above]
```

## Section notes

- **Top three.** Actionable first. If there are fewer than three real items, send fewer rather
  than padding.
- **Field events.** Only include events whose audience matches the contact titles and industry of
  this rep's accounts. Omit the link entirely when the source data has no registration URL.
- **Registrants.** Drawn from the rep's own accounts, so the follow-up is theirs to make.
- **Content.** Blog articles, eBooks, customer stories, webinars, and partner ecosystem events all
  belong here once the source set has grown to cover them.
- **New sellers.** A recipient with no assigned accounts gets a custom welcome note instead of
  this structure — never an empty message.

## Manager roll-up variant

Managers receive a consolidated roll-up of the recommendations made to their team, rather than a
single rep's message.
