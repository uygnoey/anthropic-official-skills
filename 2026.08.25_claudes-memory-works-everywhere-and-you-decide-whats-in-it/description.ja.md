# Claude のメモリはどこでも機能し、中身は自分で決める

## この記事について

プロダクト発表の記事です。チャットで使っているメモリが、Claude Cowork で使うメモリと同一になりました。Claude とどこで作業していても、すでに知っていることから始まります。Claude が覚えている内容はすべてメモリ設定でトピック単位に表示され、各項目を読み、編集し、削除できます。

あわせて三つの変更が紹介されています。会話が終わってから要約するのではなく会話中にメモリが更新されること、機微なトピックは既定でメモリに保存されないが有効化できること、そして設定にかかわらず決して保存されない情報があることです。

## どんなときに役立つか

- チャットと Cowork を行き来するたびに、優先事項、チームの指標の定義、上司が誰かといった同じ文脈を繰り返し説明している。
- Claude が自分について何を保存しているのかを推測ではなく実際に見て直したい。
- 「機微なトピックをメモリに含める」を有効にするか検討しており、それが具体的に何を変えるのか知りたい。
- Team または Enterprise の組織を管理していて、メモリの利用可否を誰が制御するのか把握する必要がある。

## 主なポイント

- **Cowork とチャットで一つのメモリ。** Cowork にメモリが加わり、それはチャットで使うものと同じです。Cowork がクラウドでタスクを実行するとき、チャットで覚えた内容がそこにあり、Cowork で出てきた内容はチャットに戻ります。数か月の会話で積み上げた文脈（第3四半期の優先事項、プロジェクトの状況など）が、Cowork にタスクを渡した瞬間から存在します。
- **一度説明すれば十分。** 上司向けの近況共有の下書きを Cowork に頼めば、その相手が誰で、どんな書き方を好むかをすでに知っています。チャットでカンファレンスのアジェンダを検討すれば、Cowork が作る予算・運営ドキュメントは参加人数、都市、登壇者を把握しています。チームが指標をどう定義しているか一度説明すれば、その後の四半期業績レビュー資料は再説明なしでその定義を使います。
- **会話中にメモリが更新される。** 会話の終了後に要約するのではなく、会話の進行中にトピックをメモリへ追加します。締め切りが9月に動いたと伝えれば、「これを覚えて」と言わなくても次の会話はすでに知っています。メモリはいつでも一時停止やリセットができます。
- **保存されたメモリは編集できるファイル。** Claude が覚えている内容は、メモリ設定の Topics 配下のファイル一覧として表示され、各ファイルを読み、編集し、削除できます。ファイルは短く、一度の修正がどこにでも効きます。会社の旧名称を1つのファイルで直せば、それ以降のすべての会話が正しく扱います。
- **機微なトピックは既定でオフ。** 既定では、健康、人種、民族、宗教的信条、政治、ジェンダー・アイデンティティなど、個人的または機微な主題に関するトピックを保存しません。「機微なトピックをメモリに含める」を有効にすると、週の作り置きレシピを提案する際にグルテンアレルギーのような情報を覚えてもらえます。
- **機微設定は今後の分だけ、保存時には通知。** 有効にしていると、これらのトピックを保存するたびに通知が表示されます。保存されるのは有効化以降の情報のみで、それ以前の内容が遡って保存されることはありません。設定はいつでもオフに戻せます。
- **決して保存されないものがある。** 機微なトピックを有効にしていても、Claude は機微な識別番号（SSN、政府発行の ID 番号など）、犯罪歴、在留資格、および利用規定（AUP）に反する内容を保存しません。そうした情報でメモリを更新できない場合、Claude がその旨を伝えます。
- **提供状況。** メモリは Free、Pro、Max プランで、ウェブ・デスクトップ・モバイルにわたり既定で有効です。機微なトピックの保存は既定で無効です。iOS と Android では、アプリを最新版に更新してください。Team と Enterprise では管理者が組織の利用可否を制御し、各ユーザーが自分で有効にするまでメモリはオフです。設定は Settings > Memory にあります。
