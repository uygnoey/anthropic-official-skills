# Claude Cowork setup checklist

A more capable model raises the value of each connection you have already made, from the folders you
have shared to the tools your team works in. Three areas to invest in.

## 1. Connect your tools

Connect Claude to the tools you use daily first:

- [ ] Email
- [ ] Calendar
- [ ] Documents
- [ ] Your team's chat
- [ ] Project and CRM tools you live in — Asana, HubSpot, Jira, Slack, and others

Each connection widens what Claude can do without you copying things in. Claude Fable 5 is good at
deciding when a tool is worth using: with your tools connected, it notices when the answer is in your
calendar or a chat thread and goes to get it, instead of waiting to be pointed there.

## 2. Tune the writing to your voice

Each new model arrives with its own writing defaults — voice, length, and the phrases it reaches for
first. The post notes Claude Fable 5 has certain defaults of its own, such as a more terse or
hard-to-follow writing style in longer sessions.

- [ ] Tailor voice, tone, and style by prompting or by adding them to your project instructions. For
      example: *"use plain, straightforward, direct language."*
- [ ] If you use memory, check occasionally what Claude has saved about your writing preferences.
- [ ] For documents where you want a specific voice, use connectors or existing files to have Claude
      read through your past writing and save what it finds as a skill it can call on next time you do
      similar work.

Fable 5 follows standing instructions more closely than earlier models, and is better at using saved
material when needed — so the instructions you write here carry further than they used to.

## 3. Revisit what you set up for earlier models

Saved instructions — skills and memory files — written for an earlier model often carry corrections
that model needed. Carried forward, old corrections can constrain a new model.

- [ ] Ask Claude Fable 5 to run the audit:

> Go through my skills and saved memory. Which still fit, and which were written for an older model?

- [ ] Remove or rewrite the corrections that only existed to work around a limitation the current
      model does not have.
